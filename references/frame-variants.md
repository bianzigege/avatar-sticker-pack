# 有边框与无边框版本

这里的“边框”指画布外围的矩形框，不是人物轮廓上的白色贴纸描边。背景透明与否、是否加文字，也分别控制。

## 选择方式

| 控制项 | 取值 | 默认行为 |
|---|---|---|
| `frame` | `none` / `rectangle` / `both` | `none`：单张成品不带矩形外框 |
| `outline` | `white` / `none` | `white`：保留克制的人物描边；用户或目标素材规格可覆盖 |

自然语言“有边框版”对应 `rectangle`，“去掉外框”对应 `none`，“两种都要”对应 `both`。要求“没有白边”时调整 `outline`，不能只删矩形框。平台专用图标遵守该用途的规则，不套用普通表情的装饰默认值。

## 去框流程

1. 优先使用独立、未加框的原始单图，保留原文件。不要从预览拼图直接截取带框单元作为成品。
2. 如果矩形框完全位于内容外围，可在不裁掉人物、道具和文字的前提下移除框所在区域。框与内容重叠时，使用原始无框图或局部图像编辑，不能直接裁断内容。
3. 固定人物身份、画风、肤色、动作和文案。用户只要求去框时，不重新设计角色、不换动作、不擅自去字或改背景。
4. 对人物和文字的整体范围做紧凑排版。建议保留画布边长约 3%—5% 的安全边距；文字靠近人物，纯图版不预留空白文字区。该比例是设计起点，不是平台强制规格。
5. 不用“删除所有白色”来去框或抠图。人物脸、手、衣领和纸张中的白色必须保留；真实透明背景不能用棋盘格图片替代。
6. 在实际发送尺寸下检查矩形残线、白色光晕、锯齿、文字可读性，以及发梢、手和辫子是否被裁掉。

## 两版交付

两版共用同一份无框画面、文案和排版。有框版仅增加外框，框应落在安全边距内，不覆盖内容；无框版不带矩形框。人物白色描边是否保留按 `outline` 执行。

```text
<pack>/
├── originals/             # 原始素材
├── framed/q/              # 有矩形框
├── frameless/q/           # 无矩形框
├── preview-framed.png
└── preview-frameless.png
```

使用相同文件名和意图编号匹配两版；有真人比例版或多个语言时，在各版本下继续分目录。预览图的网格线只属于展示排版，不得进入独立无框 PNG。

## 工具边界

这些字段是 skill 的工作流控制项，不是现有 `render_sticker_pack.py` 的命令行参数。该脚本负责加字、缩放和拼预览，不会自动识别或移除画进原图的矩形边框，也没有实现 `--frame`。应先完成必要的图像编辑，再用导出工具保存对应版本；不要向用户承诺现有脚本可以一键去除任意图片的框。

## 可直接使用的请求

> 用现有表情做无边框版，只去掉外面的矩形框，人物、肤色、动作、背景和文字保持一致。排版紧凑一点，不裁掉辫子和手，每张单独导出。

> 同一套表情输出有边框和无边框两个版本，使用相同画面与文案，分文件夹保存。人物白色描边保留。

> 做无矩形框的纯图版，不加文字，不留文字空位，人物边缘自然；背景按我指定的实底颜色保留。
