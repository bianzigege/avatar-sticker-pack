# Avatar Sticker Pack

把一张头像，快速变成一套可复用的智能体 IP 表情包。

这个 Skill 支持两条视觉轨道：

- `real`：保留头像的自然比例和识别特征，适合真人感、专业感表达。
- `q`：保留同一身份，但使用统一的 Q 版比例和更夸张的动作，适合聊天和社交场景。

每个表情都会独立输出为透明 PNG，并可统一添加文字、生成预览图和 ZIP 文件。

## 给用户的最短用法

上传一张清晰头像，然后直接说：

> 用这张头像做一套智能体 IP 表情包，分成真人版和 Q 版，每个表情单独一张，并把文字写上去。

默认会生成 6 组配对表情：

| 文案 | 使用场景 |
|---|---|
| 收到 | 确认收到任务 |
| 正在执行 | 表示任务处理中 |
| 已交付 | 表示结果已完成 |
| 可验收 | 邀请对方检查结果 |
| 我裂开了 | 表达忙乱、崩溃或超载 |
| 收工 | 表示任务结束 |

也可以只指定一个版本，例如：“只做 Q 版，生成 8 个工作场景表情。”

## 完整案例：辫子哥哥

下面用作者本人的 IP 头像演示完整流程。这个案例素材经本人授权公开，仅作为示例，不会写入通用身份规则。

### 1. 输入头像

![辫子哥哥输入头像](examples/bianzigege-demo/input-avatar.png)

用户请求：

> 用这张头像做一套智能体 IP 表情包，分成真人版和 Q 版，每个表情单独一张，并把文字写上去。

### 2. 自动提取身份锁定

Skill 会从头像中提取可复用特征，而不是把人物写死在通用 Skill 里：

- 黑色短发向后梳，清晰的眉眼，亲和而聪明的表情。
- 黑色东方感上衣。
- 长串分节辫子作为核心识别点。
- 黑白线稿为主，搭配少量橙色和蓝色情绪符号。
- 不做 3D，不做照片写实，不加入第二个人物。
- 真人版保持成人比例；Q 版保持统一的紧凑比例。

### 3. 配对规划

| 编号 | 文案 | 真人版 | Q版 |
|---|---|---|---|
| 01 | 收到 | 双手合十，礼貌回应 | 夸张点头或敬礼 |
| 02 | 正在执行 | 专注操作，带进度条 | 用力按执行按钮 |
| 03 | 已交付 | 举起完成结果 | 开心展示交付卡片 |
| 04 | 可验收 | 放大镜检查结果 | 用超大放大镜验收 |
| 05 | 我裂开了 | 克制的崩溃感 | 夸张摊在任务堆里 |
| 06 | 收工 | 合上电脑，平静下班 | 轻松喝茶收尾 |

## 适合什么场景

- AI 助手、智能体、课程老师、顾问和创作者的个人 IP。
- 微信、飞书、Discord、Slack 等聊天场景。
- “收到 / 执行中 / 已交付 / 请验收”等工作流状态表达。
- 同一头像同时需要专业版和社交版的场景。

## 设计原则

1. 头像决定“是谁”，真人版/Q版规则决定“怎么画”。
2. 每个表情单独生成，避免一张大图里人物和文字互相干扰。
3. 文字尽量在生成后统一添加，减少错别字并保持字体一致。
4. 真人版与 Q 版共用身份，不共用比例和动作库。
5. 先保证小尺寸下仍然认得出，再增加道具和情绪装饰。
