## ✨ 它能做什么

| 能力 | 说明 |
|---|---|
| 真人版 + Q版 | 同一个人设，两套比例和动作系统，互不串风格 |
| 更多表情 | `compact` 6组、`standard` 12组、`full` 24组 |
| 自定义文案 | 直接输入自己的文案，原样保留，不偷偷改字 |
| 自定义风格 | 可指定语气、配色、道具、文字样式和平台 |
| 独立交付 | 每个表情单独一张透明 PNG，同时提供预览图和 ZIP |

## 🚀 最短用法

上传一张清晰头像，然后直接说：

> 用这张头像做一套智能体 IP 表情包，真人版和 Q 版都要，生成 24 组，文字后加，透明背景，每个表情单独一张。

不想指定细节也没关系。只说“用这张头像做一套表情包”，Skill 会自动使用 `standard` 12组双版本方案。

## 🧩 四种生成模式

| 模式 | 数量 | 适合谁 |
|---|---:|---|
| `compact` | 6组 × 选定版本 | 快速试做、先看风格 |
| `standard` | 12组 × 选定版本 | 日常工作和聊天，推荐 |
| `full` | 24组 × 选定版本 | 完整覆盖工作流和情绪 |
| `custom` | 完全自定义 | 已有固定文案或品牌规范 |

真人版和 Q 版会共享身份特征，但不会共享身体比例、动作库或夸张程度。

## 🎛️ 自定义你的表情包

你可以只改一个字段，也可以一次性指定完整风格：

```text
只做 Q 版，生成 12 个工作场景表情。
语气专业但有一点幽默，黑白线稿，橙蓝点缀。
文案使用：收到、马上处理、稍等一下、请补充信息、需要确认、进度同步、
稳了、搞定、再检查一下、已交付、可验收、收工。
每张 1024×1024，透明背景，文字后加。
```

支持自定义：

- 版本：真人版、Q版或两套都要
- 数量：6、12、24，或自定义数量
- 文案：直接给出精确清单，支持中文、英文和混合文案
- 语气：专业、亲切、搞笑、克制、热血、无厘头
- 视觉：黑白线稿、品牌色、低饱和、明亮彩色等
- 道具：电脑、放大镜、茶杯、任务清单、手机、文件夹等
- 文字：黑体、手写、圆润、贴纸感，或完全不加文字
- 输出：512、1024、2048 等正方形尺寸，以及目标平台

如果自定义文案数量和指定数量不一致，Skill 会先提示你选择“减少数量、使用文案库补齐，还是重复某些文案”，不会擅自编造文案。

## 🎨 完整案例：辫子哥哥

下面用作者本人的 IP 头像演示从输入到交付的完整过程。案例素材经本人授权公开，仅作为演示，不会写入通用身份规则。

### 1. 输入头像

![辫子哥哥输入头像](examples/bianzigege-demo/input-avatar.png)

用户请求：

> 用这张头像做一套智能体 IP 表情包，分成真人版和 Q 版，每个表情单独一张，并把文字写上去。

### 2. 自动提取身份锁定

- 黑色短发向后梳，清晰眉眼，亲和而聪明。
- 黑色东方感上衣。
- 长串分节辫子作为核心识别点。
- 黑白线稿为主，橙色和蓝色情绪符号作为点缀。
- 不做 3D、不做照片写实、不加入第二个人物。
- 真人版保持成人比例；Q版保持紧凑、夸张、易读的比例。

### 3. 配对规划

| 文案 | 真人版 | Q版 |
|---|---|---|
| 收到 | 双手合十，礼貌回应 | 夸张点头或敬礼 |
| 正在执行 | 专注操作并显示进度 | 用力按下执行按钮 |
| 已交付 | 举起完成结果 | 开心展示交付卡片 |
| 可验收 | 用放大镜检查结果 | 举起超大放大镜验收 |
| 我裂开了 | 克制地扶额 | 夸张摊在任务堆里 |
| 收工 | 合上电脑准备离开 | 喝茶伸懒腰 |

## 🧠 设计原则

1. 头像决定“是谁”，风格规则决定“怎么画”。
2. 每个表情独立生成，避免人物和文字在大拼图里互相干扰。
3. 文字尽量在生成后统一添加，减少错别字并保持字体一致。
4. 真人版与 Q 版共用身份，不共用比例和动作库。
5. 先保证小尺寸下认得出，再增加道具和情绪装饰。
